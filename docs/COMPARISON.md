# DeepSeek Harness 桌面端 vs 网页端 功能对比与优化规划

## 一、架构对比

| 维度 | 网页端 (原版) | 桌面端 (当前) | 差距 |
|------|--------------|--------------|------|
| **架构** | Cordis 插件系统 + Slot 插槽 | 单体 React 应用 | 🔴 重大 |
| **状态管理** | Snapshot Store (zustand vanilla + immer) | useState 局部状态 | 🔴 重大 |
| **路由** | Slot 注册表状态变更 | 无路由 | 🟡 中等 |
| **样式** | CSS Modules + `--dsw-*` 设计令牌 | 全局 CSS | 🟡 中等 |
| **国际化** | 声明式词典 + 类型安全 t() | 无 | 🔴 重大 |
| **构建** | Vite + tsdown 插件包 | electron-vite | 🟢 基本对齐 |

## 二、UI 布局对比

### 网页端布局（三栏）
```
┌─────────────┬──────────────────────┬─────────────┐
│  Sidebar    │   Conversation       │   Details   │
│  (可折叠)   │   (主对话区)          │  (可折叠)   │
│             │                      │             │
│ - 品牌标识   │ - 会话头部            │ - 工具详情   │
│ - 工作区选择 │ - 对话视图            │ - 上下文信息 │
│ - 会话列表   │   (Chat/Trajectory)  │ - 引用展示   │
│ - 设置入口   │ - 输入栏             │             │
│             │   (附件/模型/计划)    │             │
└─────────────┴──────────────────────┴─────────────┘
```

### 桌面端当前布局（两栏）
```
┌─────────────┬──────────────────────┐
│  Sidebar    │   Main               │
│  (固定)     │   (对话区)            │
│             │                      │

│ - 模型选择   │ - 输入框             │
│ - 新建会话   │                      │
│ - 系统信息   │                      │
└─────────────┴──────────────────────┘
```

### 目标布局（对齐网页端）

┌─────────────┬──────────────────────┬─────────────┐
│  Sidebar    │   Conversation       │   Details   │
│  (可折叠)   │   (主对话区)          │  (可折叠)   │

## 五、技术选型建议

### 5.1 Markdown 渲染
```bash
pnpm add react-markdown remark-gfm rehype-highlight rehype-katex
```

### 5.2 代码高亮
```bash
pnpm add highlight.js
# 或
pnpm add shiki
```

### 5.3 状态管理
```bash
pnpm add zustand immer
```

### 5.4 UI 组件库
```bash
# 方案1: 轻量级
pnpm add @radix-ui/react-dialog @radix-ui/react-dropdown-menu @radix-ui/react-popover

# 方案2: 完整方案
pnpm add antd
```

### 5.5 虚拟滚动
```bash
pnpm add @tanstack/react-virtual
```
